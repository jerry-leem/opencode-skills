# Decisions

아직 결정 기록 없음. 중요한 선택이 발생하면 아래 형식으로 실제 내용만 추가한다.
기존 결정을 바꾸면 이전 기록을 지우지 않고 새 결정의 ID로 연결한다.

```markdown
## DEC-001: 결정 제목

- Date: 실제 결정 날짜
- Decision: 선택한 방법
- Reason: 선택 이유와 근거
- Alternatives: 검토한 대안과 제외 이유
- Impact: 영향 범위와 제약
- Authorization: 필요한 경우 사용자 승인 근거
- Status: Accepted 또는 Superseded by DEC-002
```
